# Rihan-Model - Statamic Starter Kit

Rihan-Model is a Statamic starter kit for product and portfolio-style sites with press and work collections, page builder sections, and custom business inquiry forms.

## Theme features

- Page builder support via `all_page_builder` replicator fieldset
- Custom gear and product collections with image and link fields
- Press and work collection templates with featured media and builder sections
- Two custom form endpoints:
  - `promote-your-business`
  - `promote-your-business-press`
- Uses Vite and Tailwind CSS for asset building

## Installation

Follow the [Statamic starter kit installation guide](https://statamic.dev/starter-kits/installing-a-starter-kit).
Ensure you are using **Statamic 5.x**.

### Install into an existing site

```bash
php please starter-kit:install webbycrown/rihan-model-statamic-theme
```

### Create a new site with the starter kit

```bash
statamic new my-site webbycrown/rihan-model-statamic-theme
```
